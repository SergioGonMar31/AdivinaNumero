# UD01_Actividad05_AdivinaNumero
 
Aplicación de consola en Kotlin. Se trata de adivinar un número generado aleatoriamente
 
## Tecnologías
 
- Kotlin
- IntelliJ IDEA
 
## Funcionalidades
 
- Comprobar si el número es mayor, menor o igual al número introducido por el usuario
- Generación aleatoria de un número

## Instalación y ejecución
 
1. Clona el repositorio:
```bash
   git clone https://github.com/SergioGonMar31/AdivinaNumero.git
```
2. Abre el proyecto en IntelliJ IDEA.
3. Ejecuta el archivo `Main.kt`.
